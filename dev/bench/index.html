retch benchmarks

retch against fastfetch, with fastfetch showing the same fields in each mode (generated per-mode configs, see the comparison page). Points are labelled by retch version. The ratio charts divide retch's time by fastfetch's from the same run, which cancels most of a CI runner's speed variation: below 1.0, retch is faster. On the local (real hardware) charts a triangle marks a run on battery power, which on a laptop can move the short mode by as much as the gap between the two tools; circles are on AC.
